# 项目文件 Host 插件

`@deepseek-ai/dsh-host-project-files` 通过 Typert 向浏览器客户端提供受工作区约束的目录列表、UTF-8 文件读取和带版本保护的文本保存。

## 合约

每个操作都指定已登记的工作区和相对路径。服务通过 `ctx.fs` 解析路径，拒绝工作区外的路径和受保护名称（`.git`、`.env*`、`id_rsa`），并使用文件系统目标身份校验，避免符号链接逃出工作区。

`list` 最多返回 `maxEntries` 个按字母排序的直接子项，结果不完整时标记 `truncated`。`read` 会拒绝超过 `maxFileBytes` 或不是有效 UTF-8 的内容。`save` 使用 `read` 返回的版本号，因此过期的浏览器标签页不能覆盖更新后的文件。

## 配置

| 键 | 默认值 | 含义 |
| --- | ---: | --- |
| `maxFileBytes` | 2 MiB | 单次读取可解码的最大字节数。 |
| `maxEntries` | 1,000 | 单次列出操作返回的安全子项上限。 |

## 模型体验

此插件不改变模型提示词、工具 schema、Token 预算或 KV-cache 输入，只服务于浏览器 UI 请求。

## 已知限制与延后工作

文件系统能力会在本插件应用 `maxEntries` 前返回完整目录层级；极大目录在提供方列出时仍可能消耗 Host 内存。需要流式目录能力才能限制这部分提供方工作。
